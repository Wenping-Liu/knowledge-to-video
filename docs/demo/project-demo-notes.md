# 知映KnowMotion 项目演示制作记录

- 更新日期：2026年10月29日。替换同路径旧演示，已有下载链接继续有效。
- 时长：169.5秒（约2分50秒）；1600×900、30fps；H.264视频与AAC旁白。
- 声音：本地Qwen3-TTS 1.7B CustomVoice Serena，沿用已确认音色。
- 讲解：虚构教师林老师的备课任务 → 寻找合适视频的困难 → 教材与连续讲稿 → 训练和推理机制 → 教师修改与工程复用 → 课程案例与使用入口。
- 制作：先完成连续讲稿，再按七段真实音频安排动画；本地Qwen3-ForcedAligner提供文字锚点。强制对齐仅定位给定讲稿，不证明声音无漏读。
- 画面：原创SVG与HyperFrames动效、实际编辑器录屏、已有课程片段。数值仅用于展示参数变化，并非真实模型参数。原1280×720演示画面保留在白色1600×900画布左侧，右侧合成曦曦，角色不会覆盖原画面区域。
- 曦曦：素材源于沐曦公司，由项目作者提供。复用已有挥手与眨眼分层，按原片逐字对齐时间和真实声音包络驱动近似卡通口型；不代表完整3D建模或逐音素精确唇形。角色与品牌权利不随MIT代码许可开放。
- 透明母版：169.5秒、480×600、30fps、Apple ProRes 4444 MOV，含Alpha和一条PCM旁白；本地单独交付，未将约1.36GB母版上传Git仓库。与原视频另行合成时，仅保留其中一条旁白音轨。
- 授权与来源：原创画面与合成旁白用于本项目公开演示；课程来源见本目录案例说明。第三方教材原件和个人申报资料未上传。
- 核验：本次透明母版与合成片均完整解码；视频均为5085帧、169.5秒。4个时刻验证Alpha同时包含全透明和不透明像素；合成片12个时刻抽帧检查角色与文字无重叠。AAC音频包哈希与原片一致，只有一条音轨。本次未进行独立语音识别或整片人工实时试听；口型为卡通近似，课堂学习效果尚未验证。
- 当前功能：智能体与本地工具制作。配音校准与交付为流程示意，未包装成一次完整操作实录；网页上传并自动生成属于后续研发目标。
