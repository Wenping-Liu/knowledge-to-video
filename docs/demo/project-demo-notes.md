# 新版项目演示制作记录

- 时长：114秒；1280×720、30fps；H.264视频与AAC旁白。
- 声音：本地Qwen3-TTS 1.7B CustomVoice Serena，沿用已确认音色。
- 画面：原创HyperFrames动效、实际任务配置与编辑器录屏、已有课程片段；录屏未伪造网页自动生成能力。
- 讲解：教师备课问题 → 安装与提供材料 → 训练/推理机制 → 修改权与配音失效 → 课程案例 → 使用入口。
- 计时：六段真实音频决定时长；本地Qwen3-ForcedAligner提供文字锚点，按案例名调整切点。强制对齐仅定位给定讲稿，不证明声音无漏读。
- 授权：原创画面与合成旁白用于本项目公开演示；课程原始来源与用途见同目录案例说明，第三方教材原件不随演示分发。
- 核验边界：完整解码、关键帧审查、页面运行/布局与对比度检查；尚未完成整片人工实时试听或课堂学习效果验证。
- 当前功能：Agent与本地工具制作。重配音、校准与导出由片中流程说明介绍，未将其包装成此次录屏已执行完整闭环；网页上传并全自动生成属于后续研发目标。
