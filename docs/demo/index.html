怎样核验这个 MVP

  1. 改变任务配置，检查复制与保存恢复是否一致。
  2. 打开可编辑示例，修改画面文字，保存HTML后重新打开。
  3. 修改旁白，检查旧声音变为失效；生成或导入新配音后校准并导出。
  4. 核对MP4有声音，SRT对应当前时间轴，图形与教材定义一致。

自动检查验证文件、计时与导出链路；课堂理解、讲解自然度与学习收益需要教师、学生实测。项目不声称已有全学科效果数据。
