# 教学与讲稿

每段先回答“是什么、做什么、怎样发生”。定义要准确且直白，再用贯穿的小例子解释，最后说明例子对应哪些机制、边界在哪里。例如向量可类比坐标，但维度不等同于一组预先命名的性格标签。每个知识点都覆盖对应教材内容及有价值的拓展阅读。

先列核心结论、前置概念、误解风险和证据，再写讲稿。教材原文如需引用，保留准确短句及位置记录，可自然融入旁白；按用户要求明确标注原文节选时在资料或编辑器来源处标注，不默认将引用说明烧进画面。不能为口语流畅而改变专业含义。

默认开头：“大家好，我是曦曦。本节我们要来学习……”。先讲知识点与学习目标，再从具体问题或情景进入。结尾用一句“本节课我们学习了……”概括关键机制，可配物件完成动作或全貌回收。

老师娓娓道来：句子有联系，完整意思讲完再停顿；用直接肯定的表达。必要的纠错与适用范围可用否定句，不能为数量指标牺牲准确性。避免“原文写到、教材写到、导学单写”等反复报来源口吻。屏上只留帮助理解的概念词、必要公式、代码和标注，默认不出现旁白字幕。

工程每镜可记录concept、explanation、example、scope、sourceIds、action、narration。三个教学环节可跨镜连续，切勿硬塞成每镜三句套话。结尾仍自然收束，不连续增加多轮总结。口播时长按实际配音，不以字数估算冒充实测。

审稿检查：术语先解释；数字和接口与实际材料一致；教学示意明确记录；比喻边界足够；不存在凭空引用、伪造实测或适用范围扩大。讲解质量通过阅读和学生视角判断，规则扫描只作线索。
