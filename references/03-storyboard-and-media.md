# 分镜与素材

镜头表：镜头ID/顺序、概念与旁白、具体对象、对象动作、关键时刻、构图、屏上文字、素材来源、预计时长。先锁白底漫画色板、线条和人物规则，按知识点设计大主体。概念依赖与流程用位置、连接、拆合、排序、对比来解释；缓推或淡入本身不等于机制动画。让变化发生在旁白讲到的对象上。

默认风格：纯白背景、粗墨线、适量网点与暖色，图片和短片与图示一致。可参考已装huashu-art-motion的漫画配方，先完整读取所用说明；用户对白底、问好开头、无旁白字幕的要求优先于通用配方默认。已有明确认可方向不再重选画风。

素材清单逐项标记：直接复用/拆层/搜索/生成，来源链接或原文件、权利说明、修改方式、用途、对应镜头、AI生成模型和提示词。搜可信原始资料；来源不明素材不标成自由商用。真实操作要用实际界面或可核对的代码；模拟结果标为教学示意，不伪装真实实验。

图片按可动画对象拆分，保持角色/物件一致；透明素材使用真正Alpha。图片提供静态参考图，实际运动由关键帧或原片完成。短片保留原始视频，模板通过帧序列确定性预览与导出，默认原片静音，避免混入第二位旁白。当前预处理每段最多30秒、8fps；需要更高质量时调整预处理/渲染方案并验证，不把低帧率帧序列称为原始流畅视频。

模板layer类型text/shape/image/clip。keyframes按镜头秒数设置at，可改变x/y/scale/rotation/opacity/width/height；支持linear/smooth插值。持续动作优先用关键帧，避免只在镜头起止出现变化。屏上标签必须可编辑。复杂机制可以扩展项目renderer.js；扩展后预览和导出共同使用该文件并重新验证。

素材导入：`project.py media --project ... --scene s01 --layer image1 --source ... --kind image|video`。短片使用原视频+帧序列；保留原片与使用限制。模板可编辑JSON关键帧，Agent也可直接编辑工程数据。跨镜复用素材用相同来源ID而非复制不明缓存。
