# 让画面随句意发展

先把讲稿拆成教学节拍 `beats`：每个节拍绑定旁白原样片段 `speech`，说明学生此刻看到的对象、原状态、动作、结果和依据，并引用实际 `layerIds`。镜头之间延续同一物件、问题或结果。音频生成前可写相对锚点，实际时间必须在声学对齐后确定。

## 动作表达机制

“输入文字”就让文字进入处理区；“比较误差”就把预测和目标并排；“更新参数”就让数值改变；“推理”就让输入沿已有参数的路径流动。复杂机制用分解、连线、交换、排序、逐步构建、对照或因果链解释。**图片缓推、圆点弹动、箭头反复晃动、循环缩放不能作为知识机制动画。**

每个节拍要有前后状态变化，检查能否用“因为旁白说到 X，所以对象 Y 从 A 变成 B”解释。保留必要阅读时间，同时当前课程要求整个画面连续5秒以上静止或无意义重复都须修正；不要用装饰循环来绕过此要求。运动缓急来自教学内容：关系建立可平缓移动，流程节点可迅速切入，定义出现后给读完的时间，再用具体实例推进。

`semanticRole`标明图层作用：`concept / data / relationship / evidence / decorative / camera`。另用`motionPurpose`说明动作目的：`transfer / compare / update / construct / transform / trace / highlight`；排版进场标`layout`。仅有语义声明不能证明动作有效：结构检查还排除不可见位移、装饰与循环，完整看片判断动作是否真在解释。`quality.py`报告`maxDeclaredActivityGapSeconds`，只表示声明为教学动作的图层在计时上的空档。作者可能错误标注语义，三点晃动也可能骗过数值检查，因此仍需正常速度审看；不得将这个值直接称为有效讲解覆盖率。

## 构图与文字

当前课程保留白底、主体大、无讲解员、无角落装饰和旁白字幕。色彩可以按知识对象选择，不再强制固定四个色值；一支视频内保持可辨认的对象颜色和图形语言。当前课程向已确认的第二课第一知识点Serena版看齐：大幅漫画物件、粗墨线和少量关键词。屏上保留一条简短定义、关系标签或案例必要数据，保持可编辑；详细推导由旁白配对象动作完成。避免段落式说明卡与多个文本框同时争抢注意力；不能把“补定义”理解为铺满文字。

新样片先与认可样片并排检查三点：主体是否足够大、可见文字是否比物件更抢眼、动作是否让对象的知识状态发生改变。先审一组真实渲染画面，再渲染整片；截图低文字量也不代表运动自然。

素材按用途选择而非凑数量：现场照片解释真实外观，插画建立情境，短片展示连续操作，代码/数据/机制动画负责抽象关系。原片默认静音以保持单一旁白；模拟操作、模型输出或概率值保留“教学示意”来源记录，不能伪称真实实验。生成图片尽量拆出可独立运动的对象；保留素材、来源、用途、权利条件和AI生成说明。

## 选择实现工具

已有工程优先扩展同一渲染器，预览与导出共用代码。确定性Canvas适合对象、关系和流程；Remotion适合复杂逐步构造、组合多镜或需要React组件复用的机制；HyperFrames适合已有HTML合成管线。调用已装的相关skill，按需要选工具，不为使用框架重做全部工程。

使用Remotion/HyperFrames时，HTML编辑器必须能修改讲稿、画面文本、资源和时间参数，预览与导出消费同一工程数据。交付普通MP4不能代替可编辑工程。huashu-art-motion适合分镜语法与独立成片审片；用户“5秒内要有教学变化”的要求优先于其他配方允许长时间静止的默认建议。

## 时间锚点

图层关键帧可用 `anchor: {beat:"b02", fraction:0.5, offset:0}`；`startAnchor / endAnchor`使用同样结构。`align.py`按真实配音重新计算节拍起止和图层时间，避免改文稿后只把尾帧延长。镜头全局边界可用 `boundary: sceneStart|sceneEnd`，仅适合转场/背景，不代替语义对齐。

导入短片保留原片和确定性帧序列。默认按源帧率、最高30fps处理最多30秒；低帧率原片仍是低帧率，不把插值或重复帧称为新的真实运动。需要更长/更高帧率时调整策略并核对预览与导出。素材接口见`project.py media --help`。

## SVG优先的机制图

流程、词元、参数、箭头、图表等优先用可编辑矢量对象。SVG中的对象用稳定ID分组，文字保留`text`，避免转成不可修改路径；照片/复杂手绘图保留位图并嵌入来源。编辑器“保存当前画面SVG”可导出当前静态矢量画面，渲染时每镜同时保留PNG和分组SVG参考。SVG源图不等同动画视频，运动仍由工程内的关键帧和语音锚点控制。
