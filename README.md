# knowledge-to-video

将教材、导学单和参考素材制作成知识点讲解视频的 Agent Skill。

交付内容包括有声 MP4、可编辑 HTML 工程、剪映素材、字幕、分镜配音及资料来源。默认采用白底漫画与 Qwen3-TTS 1.7B CustomVoice Serena 女声；新课程先制作一个样片，确认后继续。

## 开始使用

将本仓库下载或克隆为 `knowledge-to-video` 文件夹，向支持 Agent Skills 的助手提供 [SKILL.md](SKILL.md)，并说明教材位置和输出目录，例如：

> 请按这个 Skill，把指定文件夹中的教材和导学单制作成初中生也能理解的讲解视频。先完成一个知识点样片，按规定目录交付可编辑工程、有声视频和剪映素材。

完整操作、运行依赖和复验命令见 [使用与验证.txt](使用与验证.txt)。Skill 不包含模型权重，配音和 MP4 导出需要配置本地运行环境。

## 内容

- `SKILL.md`：入口与七个工作模块。
- `references/`：教学、分镜、声音、工程、检查和文件整理规范。
- `scripts/`：环境检测、工程创建、配音、渲染、打包、验证及本地编辑器服务。
- `assets/`：编辑器、工程结构、默认配置与交付模板。
- `tests/`：功能检查、触发用例和精简验收证据。

## 验证状态

已在 macOS Apple Silicon 上通过 40 项功能回归，包含真实 Serena 生成、有声 MP4/WebM、保存恢复和目录迁移。另通过时长显示复验。详见 [验收记录](验收记录.json) 与 [测试证据](tests/evidence)。

Windows/Linux 启动入口、PyTorch 配音适配器和宿主自动触发率尚未实际验证；教学质量与声音听感需要使用真实教材样片人工确认。
